# Ramayana Quest

Five mini-game levels based on the Ramayana: Sita Swayamvara, Dandaka Forest, Hanuman's Leap, Ram Setu, and Rama vs Ravana.

Play online: https://soumyabandi252.github.io/ramayana-quest/

Run locally: `pip install pygame` then `python main.py`

Controls: arrow keys to move, SPACE to shoot or act, ENTER to continue.
